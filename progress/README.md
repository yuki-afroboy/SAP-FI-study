# 進捗ログ

学習ラボのホーム画面下部「進捗の記録」に表示される Markdown をコピーし、
`progress/YYYY-MM-DD.md` として保存すると、学習履歴がリポジトリに残る。

週次レビューではここを見て、習熟度マップの自己評価と受入基準（要件定義 8 章）の
達成状況を突き合わせる。

## 復元用データ

学習ラボのホーム「進捗データ（復元用）」の JSON を `progress/state.json` として保存する。
「state.json として保存」ボタンからファイルで書き出せる。

週の終わりに必ずコミットすること。これがあれば、ブラウザの記録が消えても、
別の端末に移っても、ラボの「復元」に貼り付ければ元に戻る。
