# SAP-FI-study

SAP FI の知識を体系的に学ぶ学習プロジェクト。

**ゴール**: 「操作できる人」ではなく「**設計を決められる人**」になる。
3ヶ月で L3（設計判断ができる）に到達し、L4（プロジェクトを牽引する）への地図を持つ。

## 現在の進行状況

| ステップ | 成果物 | 状態 |
|---|---|---|
| 1. 要件定義 | [docs/01_requirements.md](docs/01_requirements.md) | ✅ 完了 |
| 2. カリキュラム設計 | docs/02_curriculum.md | ⬜ 未着手 |
| 3. 学習の実行（12週） | knowledge / hands-on / drills | ⬜ 未着手 |

## ディレクトリ構成（予定）

```
docs/        要件定義、カリキュラム、進行ルール
knowledge/   トピック別ナレッジ（体系・設定と挙動の因果）
hands-on/    Tコード／Fiori アプリの操作記録、シナリオ演習
drills/      一問一答・設計判断ドリルと解答
casebook/    不具合・トラブル事例集（匿名化済み）
progress/    習熟度マップ、週次ログ
```

## ⚠️ 重要ルール

本リポジトリに **顧客固有情報を記載しない**。
顧客名・会社コード・金額・マスタデータ・独自要件は書かない。
実務で得た知見は必ず抽象化・匿名化してから記録する。判断に迷う場合は書かない。
