# SAP-FI-study

SAP FI を体系的に学び、**「操作できる人」から「設計を決められる人」へ**到達するための学習プロジェクト。

3ヶ月で L3（設定と挙動の因果を理解し、Fit&Gap で根拠付きの設計判断ができる）に到達することを目標とする。

## 学習ラボ

`app/index.html` をブラウザで開くと起動する。ビルド不要。

実機では検証できない「**設定を変える → 業務挙動が変わる**」を再現するための自作ツール。
伝票を転記すると、その挙動に効いた設定（＋Tコード）が全件トレース表示される。

| 画面 | 内容 |
|---|---|
| ホーム | レベル・XP・連続学習日数・12週カリキュラム・習熟度マップ |
| 転記ラボ | 伝票を入力して転記。エラーは原因の設定つきで返る |
| IMG（設定） | 伝票タイプ・転記キー・項目ステータス・勘定マスタ・税コード・会計期間を書き換える |
| ミッション | 達成条件つきの実践課題（設定を変えないと解けない課題を含む） |
| ドリル | 一問一答を間隔反復で出題 |

GitHub Pages で公開する場合：リポジトリ設定 → Pages → Source を「GitHub Actions」に設定。

## ⚠️ 重要ルール

本リポジトリに **顧客固有情報を記載しない**。
顧客名・会社コード・金額・マスタデータ・独自要件は書かない。
実務で得た知見は必ず抽象化・匿名化してから記録する。判断に迷う場合は書かない。

学習ラボの取引先マスタなどはすべて架空のサンプルデータ。
