## A. 検証環境：会社コードの素性を読む（変更しない）

### A-1. OBY6 — 会社コードのグローバルパラメータ

担当案件の会社コードを開き、次を書き出す。**顧客固有の値はメモに残さず、構造だけ記録すること。**

| 読み取る項目 | なぜ重要か |
|---|---|
| 国 / 現地通貨 | 税手続きと財務諸表の通貨が決まる |
| 勘定コード表 | 使える勘定科目の集合が決まる |
| 会計年度バリアント | 期間数と年度の開始月が決まる |
| 転記期間バリアント | どの会社コードと締めを共有しているかが分かる |
| 事業領域財務諸表 | 事業領域を使っているかどうか |
| 為替差額の伝票タイプ等 | W4 の自動転記につながる |

**問い**：この会社コードは 4 月始まりか暦年か。それはなぜそうなっているか（法要件か、グループ方針か）。

### A-2. 会社コードが複数ある場合

一覧を出し、**どの項目が揃っていて、どの項目が国ごとに違うか**を比べる。
グローバルテンプレートの思想がそこに表れている。

### A-3. OKKP — 原価管理領域

- 割り当てられている会社コードは 1 つか複数か
- 複数なら、会計年度バリアントと勘定コード表がどう揃えられているか

**問い**：なぜこの構成にしたのだと思うか。自分なりの仮説を立ててから、可能なら先輩に確認する。

## B. サンドボックス：設定画面の場所を覚える

サンドボックスは転記できないが、**IMG 画面の現物を見て操作する**用途には十分使える。
「保存できたことを目視で確認する」までを行う。

| # | Tコード | やること |
|---|---|---|
| B-1 | OB29 | 会計年度バリアントの一覧を開き、K4 と V3 の期間定義の違いを見る。特別期間の欄がどこにあるか確認 |
| B-2 | OB37 | 会社コードへの会計年度バリアント割当画面を開く |
| B-3 | OB52 | 転記期間バリアントを開く。勘定タイプの行と、期間範囲が 2 組あること、許可グループ欄の位置を確認 |
| B-4 | OBY6 | 検証環境で読んだ項目が、設定側ではどう並んでいるかを見る |
| B-5 | 任意 | テスト用のバリアントを 1 つ作って保存し、保存できることを確認して削除する |

**注意**：他の人が使っている設定は触らない。作るなら Z で始まる自分用の値にする。

## C. 学習ラボ：期間管理の挙動

1. ミッション **M05「期間を締める」** を選ぶ
2. IMG タブ → 会計期間管理 → オープン範囲を `8 〜 8` にする
3. 転記ラボで 8 月付の伝票を転記 → 通る
4. 転記日付を 7 月に変える → `PD002` で拒否される
5. 設定トレースに `会計期間管理 OB52` が出ていることを確認する

**確認したいこと**：エラーメッセージから、原因の設定に一発でたどり着けるか。
実機の障害調査でやることと同じ動きである。
